## 1. Task 4：标定 ToF↔相机映射（**要你摆目标**）

`config.TOF_MAP` 现在是**恒等**（`{"ax":1.0,"bx":0.0,"ay":1.0,"by":0.0}`），
只在「ToF 与相机近似共轴同视场」时成立。不标定的话框可能落到桌面上，深度直接错 20mm 量级。

**流程**（每次：把目标摆好 → 在 Pi 上跑 `python3 tools/tof_probe.py --live` → 记下框中心与
`depth_mm`/三维点，同时看 ToF 块图里目标落在哪一行/列）：

1. 目标放在**画面正中** → 样本 1
2. 目标**左移**到画面约 0.3 宽处 → 样本 2
3. 目标**上移**到画面约 0.3 高处 → 样本 3

三个样本喂给 `map_report` 出四参数，写进 `config.TOF_MAP`，用
`python pc/board_exec.py --put config.py` 重新部署。

**判据**：标定后把目标放在画面 9 个不同位置，`--live` 打印的三维点与尺量的**水平位置差 < 10mm**。
达不到就加样本重来。

## 3. Task 10：端到端抓一次（**要你操作**）

```
python3 tools/grasp_once.py --box <实际框> --phase all
```

记录这几样（缺一不可）：

1. **每相拍数**（`rep['phases']` 第三项）—— 尤其 `descend` 相
2. **`s_ach_m`（下扎收尾残差）** —— 加 ToF 前的基准是实测 **2~3 mm**
3. **落点误差**（目测/尺量）
4. `depth_mm` 稳不稳（目标静止时同一位置应稳定在几十毫米内）
5. **盲区 <15cm 有没有出现过**；出现过的话，锁的是最后有效值还是没值可用

**判据**：三维点与尺量差 < 10mm、抓取不劣于加 ToF 前。不达标就回第 1 节重标映射。

## 排障速查

| 现象 | 先看这个 |
|---|---|
| app 打 `TOF WARN 探测不到模块` | 模块是不是 0 字节全无信号（`python pc/board_exec.py /tmp/t2m/recheck.py --module tof.py`）→ 供电/接线 |
| 想确认 K230 侧 UART 通不通 | **回环**：短接「座 2」的 R/T，跑 `/tmp/t2m/loopback.py` |
| 模块读不到但屏亮着 | 「屏亮」只说明**有电**，不说明信号通 —— 见 `tof.py` 文件头 |
| 帧率掉 | `STATS` 行的 `frame=` 增速。**基准：没接 ToF 时时也只有 ~4.9Hz**（不是 10Hz，这是既有水平，别误判成 ToF 拖的） |
