## 2. 三条原则

1. **几何与语义分开走安全线。**
   - ToF 点云、雷达（真实几何）→ 可影响**规划 + 紧急停车**。
   - 语义临时层（检测框推出来的占地）→ 只影响**规划绕行**，**不进 collision_monitor**。
   误检的最坏后果是多绕一段，不会在走廊中间急停。
2. **语义不画进静态栅格。** 静态图（`.pgm`）是 slam_toolbox 的产物，一次建图一份；语义层单独存、单独发布、可过期。
3. **采信一帧的前提是有可信的相机位姿**（FK + 回读稳定），不是“臂在某个固定位”。

## 4. 测距栈

| 区间 | 手段 | 用途 |
|---|---|---|
| 0.15–1.0 m | **ToF 点云**（主） | 近场障碍真实位置；目标最终停靠；收紧临时层占地 |
| > 1.0 m | **检测框底边 + 相机位姿 + 地面平面**，粗估 | 临时层占地、bearing goal 的方位；2 m 处约 ±0.2–0.3 m，俯仰每差 1° 约 10% |
| 任意 | 雷达同方位最近回波 | 交叉校验、把语义占地对齐到真实腿/边 |
| ~~视差三角化~~ | **删除**（D3） | — |
| ~~VLM 估距~~ | **不用**，单目 VLM 的距离不可信 | — |

**能力边界（写死，不假装全覆盖）**：雷达是单一平面，低于扫描面的矮物任何距离都打不到；ToF 只管 1 m 内。所以 **1 m 外、且检测器不认识的低矮物，这台车看不见**。补偿：检测器补训（D8）、建图趟写持久层、限速。

## 5. 组件

### 5.1 `cam_pose` — 相机位姿与可信度

- 输入 `/arm/feedback`，用 `arm_kin.fk` + `cam_model.camera_pose` 算 `base_link → k230_camera`、`→ tof` 的 TF。
- 每帧打可信度：

| 等级 | 条件 | 用途 |
|---|---|---|
| HIGH | 静止且回读稳定 ≥ 200 ms | 米制 + 语义 |
| MEDIUM | 回读与指令有偏差（以回读为准） | 只做语义，不做米制 |
| DROP | 运动中 / 回读漂移 / 回读是 INIT_HOME 期间的假值 | 整帧丢弃 |

- 检测帧、ToF 帧按拍摄时刻（`stamp_mono`）对齐到最近的位姿样本。

### 5.2 `tof_cloud` — ToF 点云

- 前置：ToF 切 921600（115200 物理上限只有 1.1 fps）。
- 100×100 深度 → ToF 内参回投影 → 去掉臂/爪近场（< 150 mm 硬闸 + 臂体掩码）→ 变换到 `base_link` → 地面平面滤波，保留离地 3–70 cm 的点 → 5 cm voxel 降采样 → `/tof/points`，5 Hz。
- 算力：生成侧 numpy < 1 ms/帧，单核 < 5%；主要成本在 nav2 消费侧，靠降采样控制。
- 同时产出**有效深度掩码**：ToF 视场比相机窄，画面边缘无米制，上层需知道。

### 5.3 `semantic_perception` — 语义感知（两层）

**① 临时语义层（无地图也工作，优先实现）**

1. 检测框底边 → 落地点（地面平面 + 相机位姿）。
2. 按类别给占地尺寸（椅子约 0.5×0.5 m，桌子按框宽估），**整块填满**为不可走——解决“雷达只看到几根桌腿、规划器以为能钻过去”。
3. 1 m 内用 ToF 实测收紧；附近有雷达点则对齐到雷达点。
4. 坐标系 `odom`，按时间衰减。
5. 防误检堵路：
   - 连续 N 帧确认才标；
   - “没看到”只在该区域**仍在相机视野内**时计数；转开视野则保留，30 s 自然过期；
   - 行为树恢复第一步：清语义层，退回纯雷达再规划。

**② 持久语义层（建过图的场地）**

- 文件与静态图并排：`maps/<map_version>.semantic.json`。
- 写入条件：临时层同一位置在**两次不同经过**中都出现；或建图趟人工审核；或语音/上位机人工纠正。
- 对象三态：`fresh`（近期复检看到）/ `stale`（超 TTL 或连续 3 次经过没看到，只当参考）/ `unknown`。
- 只在状态变化时写盘；`map_version` 对不上整层降级为参考。
- 用途：语音/上位机查询（“去那张桌子”）、导航先验。

```json
{
  "map_version": "nav_20261124",
  "frame": "map",
  "objects": [{
    "id": "obj-0007",
    "cls": "chair",
    "polygon": [[0.0, 0.0]],
    "z_range": [0.0, 0.85],
    "traversable": false,
    "approach_poses": [{"x": 0.0, "y": 0.0, "yaw": 0.0}],
    "state": "fresh",
    "observed_at": "2026-11-24T15:30:00+08:00",
    "source": "kpu+tof",
    "confidence": 0.82
  }]
}
```

### 5.4 接入 nav2（不写 C++）

- **首选**：nav2 Keepout Filter，语义节点持续发布衰减的禁行栅格（Python）。
- **备选**：spatio_temporal_voxel_layer（自带时间衰减），需确认 Pi 上的发行版有现成包。
- 二选一在 P1 上 Pi 实测决定。
- `/tof/points` 作为 local costmap 的 PointCloud2 observation source，并喂 collision_monitor。
- **无地图场地**：nav2 不加载静态图，global costmap 改为 odom 系滚动窗口；临时层、ToF、雷达照常。

### 5.5 目标定位器 — “去面前那张桌子”

```
目标解析（类名 + 空间约束：面前/左边/最近）
 ├─ 持久层有   → map 坐标 → approach pose → nav2
 ├─ 眼前看得到 → bearing goal 循环（下）
 └─ 看不到     → active_look 扫描找 → 找不到上报“没找到”
```

**bearing goal 循环（D7）**

1. 框中心 → 方位角 az（相机内参 + 当前位姿）。
2. 从 `base_link` 沿 az 在 global costmap 上 raycast，取**最远可通行格**，上限 3 m，离障碍留 0.5 m。
3. 发 nav2 goal，朝向指向物体。
4. 走 0.5–1.0 m 或目标框移动 > 15% → 重算。
5. 进 1 m → ToF 给真实距离 → 换成最终 approach pose。
6. 目标丢失 → 停车 → 扫描找 → 找不到上报，不瞎找。

好处：绕障由 nav2 提供；目标永远落在可通行格，不会“目标在墙里 → abort”；不新写控制器。

### 5.6 `active_look` — 主动看

**NAV_POSE**：新标的导航观察位（腕俯仰抬起，能看到车头前方地面）。俯仰角**待定**，见 §9 Q1。

| 动作 | 时机 | 限制 |
|---|---|---|
| 微俯仰 ±4° | 行驶中 | 30°/s 限速，车速 < 0.1 m/s |
| 扫描：pan {−60°, 0, +60°} × pitch {低, 中} 共 6 视角 | **停车** | 每视角停稳 200 ms，总时限 3 s |
| 回 NAV_POSE | 每次扫描结束 | 必回 |

触发：建图每走 1 m；语音“找东西”；到达目标前 1.5 m 确认；导航卡住时消歧。
主动看 = **有界扫描序列**，可预算、可复现、可测试。扫描期间帧可信度按 §5.1 判定。

### 5.7 云端 VLM

| 用法 | 判断 |
|---|---|
| 实时避障 | ❌ 4–8 s，0.25 m/s 下走 1–2 m |
| 建图期批量标注 | ✅ |
| 语音“这是什么” | ✅ 已有 |
| 疑难升级：KPU 低置信 / 不认识的类 | ✅ 停车时问一次，答案写持久层，不再重复问 |

- 输出固定 JSON schema（`cls`、`traversable`、`est_height_m`、`est_width_m`、`confidence`），不要描述句。
- **不让 VLM 给距离**；米制只信 ToF 和雷达。

### 5.8 检测模型补训（D8）

- COCO 已有 chair/couch/dining table/bench/bed/potted plant；识别差主因是**视角**（低机位、偏俯视）。有效数据 = **NAV_POSE 下用车上这台相机拍的**。
- 建议补类：凳子（COCO 无）、柜子、纸箱、垃圾桶、门、台阶、地面电线；保留 person（最高优先级）。
- 标注：车跑一圈拍几百张 → Qwen-VL 按 JSON 预标 → 人工修正。
- **合成一个模型**（导航类 + 抓取用到的类），不两个并跑（KPU 帧率减半）；沿用 yolov8n 320。

## 6. 失效降级

| 失效 | 降级 |
|---|---|
| 相机位姿 DROP / FK 读不到 | 该帧丢弃；持续则视觉链路禁用，退回纯雷达（今天的行为） |
| ToF 掉线 | 无近场米制；临时层只用粗估，占地放大；collision_monitor 仅雷达 |
| 检测频率 < 5 Hz | 临时层不用于在线避障，只累积语义 |
| 语义与雷达同方位差 > 0.5 m | 低置信，不进持久层 |
| 语义层导致规划失败 | 清语义层重规划（行为树恢复第一步） |
| 云端不可达 | 疑难类别跳过，不阻塞导航 |

## 7. 验收标准

1. **临时层避障**：无地图，路上放椅子/桌子，规划绕开整块占地，不从桌腿间钻。
2. **近场 ToF**（A/B 对照）：0.6–1.0 m 放雷达看不见的低矮物（~25 cm 凳子），0.25 m/s 直行；开视觉 → 停/绕；关视觉 → 基线会撞。
3. **误停**：空走廊 10 趟，视觉导致的停车 = **0**（最重要）。
4. **任务**：语音“去面前的凳子”，2 m 内到位，停靠误差 < 0.3 m。
5. **无地图任务**：关 map_server + AMCL，同指令用 bearing goal 到位。
6. **持久层**：10 个标注物，1 m 内查询位置误差 < 0.3 m，类名经人工审核正确。
